# Novella

Визуальная новелла на движке **Godot 4.7** с использованием плагина **Dialogic** для
диалогов и ветвления сюжета.

## Требования

- Godot 4.7 (stable), рендер GL Compatibility
- Плагины в `addons/`:
  - **Dialogic** — система диалогов и таймлайнов
  - **godot_mcp** — мост для управления редактором через MCP (опционально, для разработки)

## Как запустить

1. Откройте проект в Godot 4.7.
2. Главная сцена — `res://scenes/main_menu.tscn` (она же задана как main scene).
3. Нажмите **F5**, чтобы запустить игру, или **F6** для запуска текущей сцены.

## Настройки

Страница настроек — сцена `scenes/settings.tscn` (открывается кнопкой **Настройки** в
главном меню, кнопка **Назад** возвращает в меню). Доступно:

- **Язык** — переключение локали: системная, русский (`ru`), английский (`en`).
- **Скорость текста** — скорость появления символов (0 — мгновенно).
- **Автопролистывание** — автоматический переход к следующей реплике и его задержка.

Настройки хранит и применяет автозагрузка `scripts/game_settings.gd` (`GameSettings`).
Значения сохраняются средствами Dialogic (`Dialogic.Settings` → `user://dialogic/saves/global_info.txt`),
поэтому не зависят от слота сохранения. Из кода:

```gdscript
GameSettings.text_speed = 0.03
GameSettings.autoadvance = true
GameSettings.autoadvance_delay = 1.5
GameSettings.set_locale_by_index(2)
```

## Локализация

Перевод текста строится на штатном механизме переводов Dialogic.

- **Таблица переводов:** `locale/dialogic_translations.csv` (колонки `keys,ru,en`).
  Godot импортирует её в `.en.translation` и `.ru.translation`;
  оба файла зарегистрированы в `project.godot` (`internationalization/locale/translations`).
- **Ключи:**
  - `Text/<id>/text` — реплика (событие `Text`);
  - `Choice/<id>/text` — вариант выбора (событие `Choice`);
  - `Character/<id>/name` — имя персонажа.
- **ID** хранятся в конце строк таймлайна (`.dtl`) как `#id:<hex>` и в ресурсах
  персонажей (`.dch`) в поле `_translation_id`.
- Включено в `project.godot`: `dialogic/translation/enabled=true`,
  `dialogic/translation/original_locale="ru"`, `internationalization/locale/fallback="ru"`.

Чтобы добавить перевод новой реплики: присвойте событию `#id:<hex>` в `.dtl`,
добавьте строку `Text/<hex>/text,<ru>,<en>` в CSV и пересканируйте файловую систему
в редакторе.

> Внимание: новые автозагрузки (`GameSettings`) и настройки перевода подхватываются
> редактором только после перезапуска Godot.

## Главное меню

Сцена `scenes/main_menu.tscn` содержит:

- фон (`assets/backgrounds/main_menu.jpg`), растягивающийся на весь экран;
- заголовок игры;
- кнопки:
  - **Начать** — запускает первую главу (`res://texts/chapter1.dtl`) через Dialogic;
  - **Загрузить** — задел под систему сохранений (пока заглушка);
  - **Настройки** — задел под окно настроек (пока заглушка);
  - **Выход** — завершает игру.

## Глава 1. Ледяной кокон

Текст первой главы лежит в `texts/глава 1.md`. На его основе создан таймлайн
`texts/chapter1.dtl`, который запускается сценой `scenes/chapter1.tscn`.

Структура главы:

1. **Пролог** — заснеженный лес, Кай находит ледяной кокон с Айрис.
2. **Хранитель кедра** — дух леса рассказывает о Слезе Рассвета и даёт задание.
3. **Решение** — Кай обещает вернуться.
4. **Развилка** — выбор игрока:
   - *Пойти к реке* — быстрый путь, меньше припасов;
   - *Зайти в торговый центр* — припасы и встреча с Огоньком.
5. **Огонёк** — ветка торгового центра: Кай находит раненое огненное существо.
6. **Ночлег** — конец главы.

Персонажи: **Кай** (главный герой), **Хранитель**, **Айрис**, **Огонёк**.

### Фоны

Фоны лежат в `assets/backgrounds/` и переключаются в таймлайне событием
`[background]` с плавным появлением/затуханием (`fade`).

| Фон | Сцена | Переход |
|---|---|---|
| `bg_ch1_01_forest_path.jpg` | Сцена 1. Лес, Кай идёт по тропе | fade |
| `bg_ch1_02_clearing_cocoon.jpg` | Сцены 2–3. Поляна, кокон, Хранитель | fade |
| `bg_ch1_03_fork_river.jpg` | Сцена 4, ветка А — путь к реке | fade |
| `bg_ch1_04_mall_exterior.jpg` | Сцена 4, ветка Б — снаружи торгового центра | fade |
| `bg_ch1_05_mall_interior.jpg` | Сцена 5. Внутри ТЦ, Огонёк | fade |
| `bg_ch1_06_basement_night.jpg` | Сцена 6. Ночлег, конец главы | fade |

Глава начинается с чёрного экрана (`[background arg="#000000" fade="0"]`), затем
лес проявляется.

### Формат таймлайна Dialogic

Краткая шпаргалка по синтаксису `.dtl`, использованному в главе:

- `Имя: текст` — реплика персонажа;
- `[i]текст[/i]` — внутренний монолог / курсив (BBCode);
- `# текст` — комментарий;
- `label имя` — метка для переходов;
- `jump имя` — переход к метке;
- `- текст варианта` + события с отступом — вариант выбора игрока;
- `[background arg="res://..." fade="1.5"]` — смена фона (fade в секундах);
- `set {переменная} = "значение"` — установка переменной.

Запуск таймлайна из кода:

```gdscript
Dialogic.start("res://texts/chapter1.dtl")
```
